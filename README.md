# NestDex project page

Standalone project page for *NestDex: Nested Policy Learning with Copilot Assisted Teleoperation for Dexterous Manipulation*.

## Local preview

```bash
npm install
npm run dev
```

## GitHub Pages

The site uses relative Vite asset paths, so the same build works at both `https://cheese-zj.github.io/nestdex-site/` and the PAIR Lab route at `https://aus.bot/research/nestdex/`. GitHub Actions deploys pushes to `main` automatically.
